# Data Cleansing & Data Wrangling Portfolio Project

## Overview
This repository showcases the complete data cleaning and transformation workflow applied to raw tabular data using Microsoft Excel. The goal of this project is to implement structured data hygiene practices, enforce data constraints, and prepare a clean primary dataset for analytical modeling.

## Problem Statement
Unrefined datasets frequently contain formatting discrepancies, duplicate entries, invalid values, and inconsistent categorical codes. Processing uncleaned data leads to inaccurate business metrics and faulty analytical conclusions.

## Applied Cleaning Transformations
* Record Deduplication: Scanned and purged redundant rows across primary key constraints.
* Text Normalization: Utilized string manipulation functions (`UPPER`, `PROPER`, `TRIM`) to enforce uniform naming conventions.
* Categorical Mapping: Transformed shortened string flags into explicit, human-readable labels.
* Data Type Alignment: Standardized numerical, currency, and date data types to preserve relational accuracy.
* Conditional Binning: Engineered logical group classifications to facilitate cohort-based analysis.
